# Employee Control

Интерактивный прототип страницы «Действия сотрудников» для интернет-банка юридических лиц.

## Возможности

- выбор и поиск сотрудников;
- сводка по доступам и активности;
- фильтрация истории действий;
- просмотр необычной активности;
- аналитика по времени;
- детали событий и прототипные действия управления доступом;
- адаптивный интерфейс.

Все данные в прототипе являются вымышленными и хранятся на фронтенде.

## Локальный запуск

```bash
node server.js
```

Затем откройте `http://127.0.0.1:4173`.
